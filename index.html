01 · The Concept

The Wisdom of the Flock

In 1995, Kennedy & Eberhart simulated how bird flocks forage for food. No bird knows where the food is. No bird can see the entire field. Yet by following three simple rules, the flock reliably finds the best spot — a stunning emergent property.

Rule 1

Momentum (Inertia)

Birds carry their velocity forward. They don't stop and pivot instantly — inertia keeps them sweeping into new regions. High inertia = exploration; low inertia = fine-grained local search.

w · vt
w = inertia weight  |  Typical: 0.4 – 0.9
Rule 2

Personal Memory (Cognitive)

Each bird remembers the best spot it personally ever visited. A spring-like force pulls it back toward that remembered location, so promising personal discoveries aren't lost to social pressure.

c₁ · r₁ · (pbest − x)
c₁ = cognitive coeff  |  Typical: 1.5 – 2.0
Rule 3

Social Learning (Global Best)

All birds observe each other. Every particle feels a pull toward the single best position any member of the swarm has ever found — information propagates instantly through the flock.

c₂ · r₂ · (gbest − x)
c₂ = social coeff  |  Typical: 1.5 – 2.0

❌ Gradient Descent

  • Needs a derivative — function must be differentiable
  • One solution at a time
  • Easily trapped in local minima
  • Sensitive to starting point
VS

✅ Particle Swarm Optimization

  • Derivative-free — works on any black-box function
  • Entire population explores in parallel
  • Escapes local minima through social diversity
  • Robust to initial conditions
02 · The Equation

One Formula Drives the Entire Swarm

Those three rules become three vectors. Each iteration, every particle adds them to get a new velocity, then moves by that velocity. Hover each term to understand it.

vt+1 = w · vt
Inertia
The particle continues in its current direction. Large w keeps it exploring; small w makes it converge.
+ c₁ · r₁ · (pbest − xt)
Cognitive "Nostalgia"
A spring pulling toward the particle's own best memory. r₁ ∈ [0,1] is drawn randomly each step.
+ c₂ · r₂ · (gbest − xt)
Social "Peer Pressure"
A spring toward the best spot found by the entire swarm. This is how one discovery spreads to everyone.
xt+1 = xt + vt+1 (position update — always last)
w Inertia weight 0 – 1.4
c₁ Cognitive coefficient 0 – 3
c₂ Social coefficient 0 – 3
r₁, r₂ Uniform random [0, 1] redrawn each step
pbest Particle's personal best position stored per particle
gbest Global best position (whole swarm) shared & updated each iter

03 · The Algorithm

The Loop That Makes the Swarm Think

PSO's pseudocode fits on an index card. Here it is — with every step explained in plain English.

Pseudocode
minimize f(x)

# Initialise
for each particle i:
    xi ← random position
    vi ← random small velocity
    pbesti ← xi

# Main loop
repeat until stopping criterion:
    for each particle i:
        fi ← f(xi)          # evaluate
        if fi < f(pbesti):
            pbesti ← xi   # memory
    gbest ← argmin f(pbesti)   # share
    for each particle i:
        r₁, r₂ ← U(0, 1)
        vi ← w·vi + c₁r₁(pbesti−xi)
              + c₂r₂(gbest−xi)
        xi ← xi + vi         # move

return gbest
1

Scatter the Birds

Particles are placed at random positions in the search space. Velocities are small random vectors — nobody has a plan yet.

2

Probe the Landscape

Evaluate f(xᵢ) for every particle. This is the only time the problem is touched — and usually the most expensive step.

3

Update Memories

If a particle found a better spot than its personal best, it updates pbestᵢ. Each bird keeps its own track record.

4

Elect the Leader

The best pbest across all particles becomes gbest — instantly known to every particle in the swarm.

5

Fly! (Update Velocity & Position)

Apply the three-force equation. Add the new velocity to get the next position. The swarm moves. Repeat.

✓

Stop When Converged

Stopping criteria: max iterations reached, f(gbest) below a threshold, or no improvement for k rounds.

🔢
Iteration Budget Fixed maximum (e.g. 100 iterations) — simplest; always terminates.
🎯
Good Enough f(gbest) drops below a target threshold — stop as soon as quality is sufficient.
📉
Stagnation gbest hasn't improved for k consecutive iterations — the swarm has converged.
🔵
Collapse All particles within a tiny radius — population diversity ≈ 0.
